# Telegram-бот «Авантерн Телематика Помощник» #

Виртуальный помощник для клиентов компании «Авантерн Телематика» — федерального провайдера решений в области ГЛОНАСС и GPS-мониторинга.

Бот отвечает на типовые вопросы о компании, услугах, контактах, ценах и партнёрской сети. Проект выполнен в рамках Кейс-задачи № 3 и адаптирован для работы в условиях ограничений доступа к Telegram API (с использованием VPN и отключением проверки SSL-сертификатов).

## 📌 Возможности бота ##

Ответы на часто задаваемые вопросы (FAQ):
- Общая информация о компании
- Услуги и направления деятельности
- Контактные данные (адрес, телефон, сайт, режим работы)
- Информация о платформе Wialon и телематическом оборудовании
- Стоимость и порядок заказа
- Партнёрская сеть в 200 городах России

Распознавание ключевых слов в сообщениях пользователя (регистр не важен)
Простое расширение базы знаний
Команды /start и /help с подсказками

## 🛠️ Технологии ##

Python 3.8+
pyTelegramBotAPI (telebot) – библиотека для работы с Telegram Bot API
Requests – для HTTP-запросов с отключенной проверкой SSL (совместимость с VPN)
Библиотека разработана без использования сложных NLP-инструментов (простое сравнение строк), что делает её лёгкой и быстрой
